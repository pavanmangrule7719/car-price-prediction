# AI Data Intelligence Platform

Machine Learning project for predicting Audi car prices.

## Project Phases

### Phase 1
Dataset + EDA

### Phase 2
Data Cleaning

### Phase 3
Preprocessing Pipeline

### Phase 4
Train/Test Split

### Phase 5
Multiple Models

- Linear Regression
- Decision Tree Regressor
- Random Forest Regressor

### Phase 6
Model Comparison

Evaluation metrics:

- MAE
- MSE
- RMSE
- R²

### Phase 7
Hyperparameter Tuning

- GridSearchCV
- RandomizedSearchCV

### Phase 8
Final Model + Pipeline Save

The complete preprocessing + model pipeline is saved using pickle.

### Phase 9
Prediction System

The saved model is loaded and used for new car price predictions.

### Phase 10
GitHub + Documentation

Project documentation and version control.
